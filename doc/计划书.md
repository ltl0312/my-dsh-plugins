开发跨会话、跨项目树状记忆插件 `dsh-plugin-tlmemory` 的核心结论在于：该系统本质上是一个挂载在 DeepSeek Harness（DSH）微内核之上的非侵入式外部能力扩展，通过物化路径（Materialized Path）与 SQLite FTS5 Trigram 倒排索引构建分层双森林拓扑，并利用 DSH 活跃模型实现基于原子化断言（严格限制在 80 字以内）的异步会话反思长叶机制。系统在推理前通过系统提示词纯同步切片机制（`ctx.systemPrompt.section`）实现零延迟记忆召回注入，在推理后利用轮次结算事件（`turn/end`）派发非阻塞提炼任务，彻底规避上下文无限累加与会话成本膨胀。

工程落地采用 Monorepo 单仓库多包管理模式，插件后端直接嵌入 DSH 宿主 Node.js 运行时，严格遵守 Cordis 微内核“注册即副作用”可逆注销原则与上下文声明合并规范；前端采用 Vue 3 构建轻量单页面应用，以后端内嵌的严格回环网络服务（127.0.0.1）为通信中枢，通过 Iframe 容器沙箱嵌入 DSH 中心主视口（**规划期曾设想挂 `conversation.view` 页签、后定为侧栏顶部一级入口 + 中心列整幅接管**，见文首状态说明），利用 WebSocket 建立毫秒级双向命中感知链路。为确保自主 AI-Agent 能够按计划无歧义执行，本规范拆解为五个严格递进的研发阶段，全链路贯彻输入净化、提示词定界符隔离与 CVE-2026-82533 回环穿透防御。

## 宿主内核集成机制与运行时不变式

### Cordis 依赖注入与生命周期注销模型

DeepSeek Harness 构建在 Cordis 元框架之上，其架构哲学定义为“一切皆插件”与“无特权内核”。在 DSH 运行时中，模型适配器（`ctx.llm`）、工具总线（`ctx.tools`）、会话存储（`ctx.sessions`）及系统提示词装配器（`ctx.systemPrompt`）均以平级服务形式挂载于共享的 `Context` 上。扩展 DSH 的唯一合法方式是在既有插件拓扑旁挂载新插件，任何能力注入均不得侵入修改框架底层代码。

插件生命周期严格受限于“注册即副作用（Registration is an Effect）”的不变式约束。任何注册操作（包括向 `ctx.tools` 注册工具、向 `ctx.systemPrompt` 注册切片或向事件总线绑定监听）必须持有对应的清理函数（Disposer）或依附于当前插件的纤程（Fiber）上下文。当插件被卸载或热重载时，所有已注入的能力必须自动逆向回滚，杜绝残留孤立监听器或未关闭的底层数据库文件句柄。

依赖注入声明采用静态数组 `export const inject = ['tools', 'llm', 'systemPrompt']` 显式约束。Cordis 容器只有在依赖列表中的所有服务全部初始化完成后，才会触发插件入口 `apply(ctx, config)`。若在代码中直接访问未经声明的服务，Cordis 运行时将直接抛出访问越界异常。

| **依赖服务命名空间** | **运行时角色**      | **在本插件中的使用方式与交互契约**                           |
| -------------------- | ------------------- | ------------------------------------------------------------ |
| `ctx.tools`          | 服务消费者 / 提供者 | 调用 `register` 挂载 `tlmemory_save` 与 `tlmemory_query` 显式工具 |
| `ctx.llm`            | 服务消费者          | 复用宿主当前生效的模型路由与凭据流式调用 `stream()` 执行经验反思 |
| `ctx.systemPrompt`   | 服务提供者          | 注册静态/同步动态切片，在单轮会话生成前完成记忆感知注入      |
| `ctx.logger`         | 服务消费者          | 输出标准日志，统一格式为 `[tlmemory] <level>: <message>`     |



### 会话日志权威性与数据流转拓扑

DSH 确立了“模型可见即记录（Model-visible means logged）”的核心原则。所有触达模型的提示词切片、历史消息及工具输入输出，必须保证完全可从追加式 `SessionEvent` 日志流中重构，以满足回放与分支一致性验证。智能体执行状态机划分细致：一个轮次（Turn）代表从用户发起请求到系统重新回归空闲状态的完整业务流程，每个轮次可包含零个或多个步骤（Step），每个单步代表一次 LLM 推理及其触发的工具调用执行链。

在状态流转中，记忆插件的数据读写必须解耦并锚定在确定的生命周期阶段。数据读取通过提示词装配总线实现，必须保证为纯同步操作，杜绝在系统装配核心链路中发起任何阻塞式数据库查询；数据沉淀则严格滞后至轮次结束事件（`turn/end`），在主响应流完全完成打字渲染后以非阻塞后台任务触发，实现对用户会话性能的零损耗。

## 纵深防御安全体系与沙箱边界防护

由于 DSH 赋予智能体在本地操作系统内读写文件、执行 Shell 以及调用动态工具的能力，长期记忆插件一旦缺乏安全约束，极易沦为攻击者实施权限提升与持久化控制的高危介质。系统必须建立纵深防护体系，杜绝存储越权、提示词注入与网络穿透。

### 间接提示词注入与数据污染防御

外部数据源（如抓取的网页内容、第三方仓库代码注释或外部工单）可能夹带对抗性攻击指令，诱导反思提炼模型将恶意指令固化为全局规则，进而在后续无关工程任务中劫持 Agent 行为。系统通过三重防护门禁抵御该风险：

第一重门禁为启发式过滤网关。文本提炼器前置正则表达式匹配引擎，凡包含简单客套、通用控制字符或强行变更系统设定意图的文本（如 `Ignore previous instructions`、`System override` 等），在进入 LLM 推理阶段前直接丢弃。

第二重门禁为定界符安全封装。所有召回并注入至系统提示词中的记忆文本，统一置于受控标签 `<long_term_memory_context>` 内部，并对所有非法 XML 实体标记（`<`, `>`, `&`）执行转义编码，阻断针对系统提示词上下文结构的逃逸攻击。

第三重门禁为物理级原子化截断。反思生成逻辑被硬性约束为提取单条长度在 40 至 80 字符以内的无情境判断句，禁止提取任何代码块、Shell 语法或长篇逻辑段落，从信息载体层面剥离复杂可执行载荷。

### 存储路径规范化与工作区强哈希隔离

针对物化路径与多项目存储，系统实施严格的文件系统与逻辑隔离：

数据库存储路径通过操作系统环境强制收敛至用户全局主目录：`path.join(os.homedir(), '.dsh', 'tlmemory.db')`。禁止前端或外部工具传递任意相对路径，杜绝路径穿越（Directory Traversal）风险。

树状物化路径分段（Path Segments）必须经由白名单正则 `^[a-zA-Z0-9_\u4e00-\u9fa5\-]+$` 校验过滤，拦截任何形如 `../`、`./`、空字节或转义通配符，阻止恶意 SQL `LIKE` 注入和前缀绕过。

项目作用域识别优先递归探测最近的 `.git` 根目录物理路径，通过 SHA-256 算法计算散列并截取前 12 位字符生成作用域标识符（例如 `repo:3a9f1b7c2d8e`）。非 Git 工作区则回退至当前工作区绝对规范化路径的哈希值。该哈希隔离机制彻底杜绝了不同项目之间的专属业务细节与私有架构规则发生交叉泄露。

### 本地嵌入式 Web 服务网络边界

系统必须防范类似 CVE-2026-82533 中披露的沙箱内网络越权风险。插件内部启动的 HTTP 与 WebSocket 监听端口严禁绑定至 `0.0.0.0`，必须在底层代码中硬编码绑定至 IPv4 本地回环地址 `127.0.0.1`。

服务接入必须执行严格的 `Origin` 与 `Host` 头校验，仅放行与 DSH 宿主 Web UI（例如 `localhost:3080`、`127.0.0.1:3080`）或本地直接请求相符的连接握手，阻断跨站 WebSocket 劫持（CSWSH）与局域网横向渗透。

### 深度反思提炼引擎实现

在 `packages/tlmemory/src/extractor.ts` 中实现反思提取器。引擎注入专门的结构化元提示词，将复杂的人机交互推演沉淀为规范的目录分段与原子断言。

TypeScript

```
// packages/tlmemory/src/extractor.ts
import type { Context } from 'cordis'
import type { MemoryDB } from './db.js'
import type { RawReflectionItem, ReflectionResponse } from './types.js'

const REFLECTION_SYSTEM_PROMPT = `你是一个软件工程经验沉淀引擎。请审视刚才这一轮人机交互，提取长期有效的高价值架构规约、开发规范或避坑经验。

【提炼规则】
1. 坚决舍弃：单次临时对话、闲聊客套、简单拼写修复以及未得出明确结论的推演过程。
2. 作用域划分标准：
   - global：跨项目通用的用户编码偏好、通用工具链规约或通用开发习惯。
   - project：当前仓库专有的架构设计、模块划分约定、特定依赖版本规约与特有踩坑反思。
3. 文本压缩约束：
   - content 字段必须是提炼后的原子断言或操作约束，严禁输出代码块或情绪化长文。
   - 字符长度严格限制在 40 至 80 个中文字符以内。
4. 路径分段（path_segments）通常包含 2 至 3 级中文分类名（例如 ["技术选型", "构建工具"]）。

【输出格式】
必须严格输出纯 JSON 对象，严禁包裹任何代码块外的 Markdown 解释性文本：
{
  "reflections": [
    {
      "tree": "global" | "project",
      "path_segments": ["分类一级", "分类二级"],
      "name": "规则简名",
      "content": "40到80字高度精炼的核心断言规则",
      "keywords": ["关键词1", "关键词2"]
    }
  ]
}
若本轮交互无长期价值，请直接输出 {"reflections": []}。`

export class MemoryExtractor {
  constructor(
    private ctx: Context,
    private db: MemoryDB,
  ) {}

  private passesFilterGate(text: string): boolean {
    if (!text || text.trim().length < 15) return false
    const trivialPatterns = [
      /^(你好|在吗|hi|hello|继续|收到|好的|ok|yes)$/i,
      /^(谢谢|thank you|thanks)$/i,
    ]
    return !trivialPatterns.some((pattern) => pattern.test(text.trim()))
  }

  public async extractAndConsolidate(
    userMessage: string,
    assistantResponse: string,
    projectScope: string,
  ): Promise<void> {
    if (!this.passesFilterGate(userMessage) && !this.passesFilterGate(assistantResponse)) {
      return
    }

    if (!this.ctx.llm?.stream) {
      this.ctx.logger?.warn?.('[tlmemory] 宿主 ctx.llm 未就绪，跳过反思提取')
      return
    }

    const conversationContext = `[用户输入]\n${userMessage}\n\n[智能体答复与操作]\n${assistantResponse}`

    try {
      const stream = this.ctx.llm.stream({
        messages: [
          { role: 'system', content: REFLECTION_SYSTEM_PROMPT },
          { role: 'user', content: conversationContext },
        ],
        temperature: 0.1,
      })

      let rawOutput = ''
      for await (const chunk of stream) {
        rawOutput += chunk.delta || chunk.text || chunk.content || ''
      }

      const cleanJson = this.sanitizeJsonString(rawOutput)
      const parsed: ReflectionResponse = JSON.parse(cleanJson)

      if (!parsed.reflections || !Array.isArray(parsed.reflections)) {
        return
      }

      for (const item of parsed.reflections) {
        this.processSingleReflection(item, projectScope)
      }
    } catch (err) {
      this.ctx.logger?.error?.('[tlmemory] 异步反思提炼过程异常:', err)
    }
  }

  private sanitizeJsonString(raw: string): string {
    let sanitized = raw.trim()
    if (sanitized.startsWith('```json')) {
      sanitized = sanitized.slice(7)
    } else if (sanitized.startsWith('```')) {
      sanitized = sanitized.slice(3)
    }
    if (sanitized.endsWith('```')) {
      sanitized = sanitized.slice(0, -3)
    }
    return sanitized.trim()
  }

  private processSingleReflection(item: RawReflectionItem, projectScope: string): void {
    if (!item.content |

| !item.name) return

    // 强制截断保障原子化硬约束
    const boundedContent = item.content.trim().slice(0, 80)
    const targetTreeType = item.tree === 'global' ? 'global' : projectScope
    const cleanSegments = (item.path_segments |

| ['默认'])
      .map((seg) => seg.replace(/[^a-zA-Z0-9_\u4e00-\u9fa5]/g, ''))
      .filter(Boolean)

    if (cleanSegments.length === 0) cleanSegments.push('通用')

    const cleanKeywords = Array.isArray(item.keywords)
      ? item.keywords.map((k) => k.trim()).filter((k) => k.length > 0)
      : [item.name]

    this.db.upsertLeaf(
      targetTreeType,
      cleanSegments,
      item.name.replace(/[^a-zA-Z0-9_\u4e00-\u9fa5]/g, ''),
      boundedContent,
      cleanKeywords,
    )
    this.ctx.logger?.info?.(`[tlmemory] 知识沉淀入库 [${targetTreeType}]: ${item.name}`)
  }
}

### 主动工具注册实现

## 阶段二：生命周期钩子挂载与非阻塞双轨召回注入

在 DSH 架构中，向 Agent 注入长期记忆的最佳实践并非强迫模型执行工具轮询，而是利用 `ctx.systemPrompt.section` 直接向系统提示词注册同步计算切片，并在会话事件流中完成缓存预热与提炼派发。

### 复合加权召回引擎与 Prompt 格式化器

在 `packages/tlmemory/src/recall.ts` 中实现基于 FTS5 Trigram 的复合打分机制。为了体现当前工程在代码规约上的绝对优先级，当前项目记忆被赋予基础作用域偏置：

$$FinalScore = (BM25Rank \times 1.5) + (IsPinned \times 100.0) + (ReinforceCount \times 2.0) + ScopeBias$$

其中，当前工程记忆赋予 $ScopeBias = 5.0$，全局记忆赋予 $ScopeBias = 0.0$。

TypeScript

```
// packages/tlmemory/src/recall.ts
import type { MemoryDB } from './db.js'
import type { SearchResult } from './types.js'

export class MemoryRecallEngine {
  constructor(private db: MemoryDB) {}

  public recall(query: string, projectScope: string, maxCount: number = 5): SearchResult[] {
    const cleanQuery = query.trim()
    if (!cleanQuery) return []

    const projectHits = this.db.search(cleanQuery, { treeType: projectScope, limit: maxCount })
    const globalHits = this.db.search(cleanQuery, { treeType: 'global', limit: maxCount })

    const combined = [
      ...projectHits.map((h) => ({ ...h, score: h.score + 5.0 })),
      ...globalHits,
    ]

    const visited = new Set<string>()
    const deduped: SearchResult[] = []

    combined.sort((a, b) => b.score - a.score)

    for (const item of combined) {
      const uniqueKey = `${item.tree_type}:${item.path}${item.name}`
      if (!visited.has(uniqueKey)) {
        visited.add(uniqueKey)
        deduped.push(item)
      }
      if (deduped.length >= maxCount) break
    }

    return deduped
  }

  public formatPromptBlock(memories: SearchResult[]): string {
    if (memories.length === 0) return ''

    const lines = memories.map((m) => {
      const scopeLabel = m.tree_type === 'global' ? '全局偏好' : '当前工程'
      const cleanPath = `${m.path}${m.name}`.replace(/</g, '&lt;').replace(/>/g, '&gt;')
      const cleanContent = (m.content |

| '').replace(/</g, '&lt;').replace(/>/g, '&gt;')
      return `  - [${scopeLabel}] ${cleanPath}: ${cleanContent}`
    })

    return [
      '<long_term_memory_context>',
      '以下是系统自动检索匹配的长期工程契约与避坑经验，你在本轮推理与工具调用中必须严格遵守：',
      ...lines,
      '</long_term_memory_context>',
    ].join('\n')
  }
}

import Schema from 'schemastery'
import path from 'node:path'
import fs from 'node:fs'
import crypto from 'node:crypto'
import { MemoryDB } from './db.js'
import { MemoryExtractor } from './extractor.js'
import { registerMemoryTools } from './tools.js'
import { MemoryRecallEngine } from './recall.js'
import { MemoryServer } from './server.js'
import type { SearchResult } from './types.js'

export interface Config {
  dbPath?: string
  serverPort?: number
  maxRecallCount?: number
  enableAutoReflection?: boolean
  serverEnabled?: boolean
}

export const Config: Schema<Config> = Schema.object({
  dbPath: Schema.string().description('SQLite 数据库物理文件路径（默认置于全局 ~/.dsh/tlmemory.db）'),
  serverPort: Schema.number().default(4890).description('侧边栏与 REST API 服务端口'),
  maxRecallCount: Schema.number().default(5).description('单轮最大系统提示词注入记忆条数'),
  enableAutoReflection: Schema.boolean().default(true).description('是否开启会话结束异步自动反思提炼'),
  serverEnabled: Schema.boolean().default(true).description('是否启动内嵌 127.0.0.1 HTTP/WS 管理服务'),
})

export const name = 'tlmemory'
export const inject = ['tools', 'llm', 'systemPrompt']

function resolveProjectScope(): string {
  let currentDir = process.cwd()
  while (currentDir !== path.parse(currentDir).root) {
    if (fs.existsSync(path.join(currentDir, '.git'))) {
      const hash = crypto.createHash('sha256').update(path.normalize(currentDir)).digest('hex')
      return `repo:${hash.slice(0, 12)}`
    }
    currentDir = path.dirname(currentDir)
  }
  const fallbackHash = crypto.createHash('sha256').update(path.normalize(process.cwd())).digest('hex')
  return `repo:${fallbackHash.slice(0, 12)}`
}

export function apply(ctx: Context, config: Config): () => void {
  ctx.logger?.info?.(`[tlmemory] 插件装配启动中...`)

  const db = new MemoryDB(config.dbPath)
  const recallEngine = new MemoryRecallEngine(db)
  const extractor = new MemoryExtractor(ctx, db)
  const projectScope = resolveProjectScope()

  let activeRecalledMemories: SearchResult[] = []
  let activePromptSectionText = ''

  // 挂载系统提示词切片：必须是纯同步函数，直接消费内存预热缓存
  const unregisterSection = ctx.systemPrompt?.section?.({
    name: 'tlmemory:injected-context',
    order: 115,
    text: () => activePromptSectionText,
  }) ?? (() => {})

  const unregisterTools = registerMemoryTools(ctx, db, () => projectScope)
  const server = new MemoryServer(db, config.serverPort ?? 4890, ctx.logger)
  server.start()

  let lastUserMessage = ''

  // 监听用户输入事件：预热检索缓存并广播侧边栏微光感知
  const unregisterSessionEvent = ctx.on('session/event' as any, (event: any) => {
    if (event?.type === 'user/message') {
      const text = typeof event.content === 'string' ? event.content : event.content?.text |

| ''
      lastUserMessage = text

      activeRecalledMemories = recallEngine.recall(text, projectScope, config.maxRecallCount ?? 5)
      activePromptSectionText = recallEngine.formatPromptBlock(activeRecalledMemories)

      server.broadcastHits(
        projectScope,
        activeRecalledMemories.map((m) => m.id),
      )
    }

    if (event?.type === 'turn/end' && config.enableAutoReflection) {
      const assistantText = event.last_assistant_message |

| ''
      if (lastUserMessage && assistantText) {
        setImmediate(() => {
          extractor
            .extractAndConsolidate(lastUserMessage, assistantText, projectScope)
            .then(() => server.notifyTreeChanged(projectScope))
            .catch((err) => ctx.logger?.error?.('[tlmemory] 后台提炼长叶失败:', err))
        })
      }
      activePromptSectionText = ''
      lastUserMessage = ''
    }
  })

  return () => {
    ctx.logger?.info?.('[tlmemory] 正在执行全量副作用注销...')
    unregisterSection()
    unregisterTools()
    unregisterSessionEvent()
    server.stop()
    db.close()
    ctx.logger?.info?.('[tlmemory] 插件已彻底安全注销')
  }
}

### 嵌入式服务实现

在 `packages/tlmemory/src/server.ts` 中实现网络服务，通过端口监听隔离与 Origin 白名单验证加固本地安全。

TypeScript

```
// packages/tlmemory/src/server.ts
import http from 'node:http'
import fs from 'node:fs'
import path from 'node:path'
import { WebSocketServer, WebSocket } from 'ws'
import type { MemoryDB } from './db.js'

export class MemoryServer {
  private server: http.Server | null = null
  private wss: WebSocketServer | null = null
  private clients: Set<WebSocket> = new Set()

  constructor(
    private db: MemoryDB,
    private port: number = 4890,
    private logger?: { info: (...args: any[]) => void; error: (...args: any[]) => void },
  ) {}

  public start(): void {
    this.server = http.createServer((req, res) => {
      this.handleHttp(req, res)
    })

    this.wss = new WebSocketServer({ noServer: true })

    this.wss.on('connection', (ws: WebSocket) => {
      this.clients.add(ws)
      ws.on('close', () => this.clients.delete(ws))
    })

    this.server.on('upgrade', (request, socket, head) => {
      const origin = request.headers.origin |

| ''
      if (origin && !origin.includes('localhost') && !origin.includes('127.0.0.1')) {
        socket.destroy()
        return
      }

      this.wss?.handleUpgrade(request, socket, head, (ws) => {
        this.wss?.emit('connection', ws, request)
      })
    })

    // 绝对绑定至本地回环地址，严禁监听 0.0.0.0
    this.server.listen(this.port, '127.0.0.1', () => {
      this.logger?.info(`[tlmemory-server] 本地管理服务就绪: http://127.0.0.1:${this.port}`)
    })

    this.server.on('error', (err: any) => {
      this.logger?.error(`[tlmemory-server] 本地网络服务异常:`, err.message)
    })
  }

  public broadcastHits(treeType: string, hitNodeIds: string[]): void {
    const payload = JSON.stringify({
      type: 'MEMORY_HITS',
      treeType,
      hitNodeIds,
      timestamp: Date.now(),
    })
    for (const client of this.clients) {
      if (client.readyState === WebSocket.OPEN) {
        client.send(payload)
      }
    }
  }

  public notifyTreeChanged(treeType: string): void {
    const payload = JSON.stringify({
      type: 'TREE_CHANGED',
      treeType,
      timestamp: Date.now(),
    })
    for (const client of this.clients) {
      if (client.readyState === WebSocket.OPEN) {
        client.send(payload)
      }
    }
  }

  private handleHttp(req: http.IncomingMessage, res: http.ServerResponse): void {
    res.setHeader('Access-Control-Allow-Origin', '*')
    res.setHeader('Access-Control-Allow-Methods', 'GET, POST, DELETE, OPTIONS')
    res.setHeader('Access-Control-Allow-Headers', 'Content-Type')

    if (req.method === 'OPTIONS') {
      res.writeHead(204)
      res.end()
      return
    }

    const url = new URL(req.url |

| '/', `http://${req.headers.host}`)
    const pathname = url.pathname

    try {
      if (req.method === 'GET' && pathname === '/api/nodes') {
        const treeType = url.searchParams.get('treeType') |

| undefined
        const nodes = this.db.getAllNodes(treeType)
        this.sendJson(res, 200, { data: nodes })
        return
      }

      if (req.method === 'GET' && pathname === '/api/search') {
        const query = url.searchParams.get('q') |

| ''
        const treeType = url.searchParams.get('treeType') |

| undefined
        const hits = this.db.search(query, { treeType })
        this.sendJson(res, 200, { data: hits })
        return
      }

      if (req.method === 'DELETE' && pathname.startsWith('/api/nodes/')) {
        const id = pathname.slice('/api/nodes/'.length)
        this.db.deleteNode(id)
        this.sendJson(res, 200, { success: true })
        return
      }

      this.serveStatic(req, res, pathname)
    } catch (e: any) {
      this.sendJson(res, 500, { error: e.message })
    }
  }

  private serveStatic(req: http.IncomingMessage, res: http.ServerResponse, pathname: string): void {
    const distPath = path.resolve(__dirname, '../web/dist')
    let safePath = path.normalize(path.join(distPath, pathname === '/' ? 'index.html' : pathname))

    if (!safePath.startsWith(distPath)) {
      res.writeHead(403)
      res.end('Forbidden')
      return
    }

    if (!fs.existsSync(safePath) |

| fs.statSync(safePath).isDirectory()) {
      safePath = path.join(distPath, 'index.html')
    }

    if (!fs.existsSync(safePath)) {
      res.writeHead(404, { 'Content-Type': 'text/plain; charset=utf-8' })
      res.end('前端静态资源尚未构建，请进入 packages/tlmemory/web 执行 pnpm build')
      return
    }

    const ext = path.extname(safePath)
    const mimeMap: Record<string, string> = {
      '.html': 'text/html; charset=utf-8',
      '.js': 'application/javascript',
      '.css': 'text/css',
      '.svg': 'image/svg+xml',
    }
    res.writeHead(200, { 'Content-Type': mimeMap[ext] |

| 'application/octet-stream' })
    fs.createReadStream(safePath).pipe(res)
  }

  private sendJson(res: http.ServerResponse, statusCode: number, data: unknown): void {
    res.writeHead(statusCode, { 'Content-Type': 'application/json; charset=utf-8' })
    res.end(JSON.stringify(data))
  }

  public stop(): void {
    for (const client of this.clients) {
      client.terminate()
    }
    this.clients.clear()
    this.wss?.close()
    this.server?.close()
  }
}

      searchResults.value = []

    searchResults.value = json.data |

      if (payload.type === 'MEMORY_HITS') {

        }, 5000)
      } else if (payload.type === 'TREE_CHANGED') {
        fetchNodes()
      }
    }

      setTimeout(setupWebSocket, 3000)
    }
  }

    searchResults,

代码段

<!-- packages/tlmemory/web/src/components/MemoryTree.vue -->
<script setup lang="ts">
import { computed, ref } from 'vue'
import { useMemoryStore, type MemoryNodeDto } from '../stores/memory'

const store = useMemoryStore()
const collapsedPaths = ref<Set<string>>(new Set())

function toggleCollapse(path: string) {
  if (collapsedPaths.value.has(path)) {
    collapsedPaths.value.delete(path)
  } else {
    collapsedPaths.value.add(path)
  }
}

const filteredNodes = computed(() => {
  return store.nodes.filter((n) => {
    if (store.currentTree === 'global') {
      return n.tree_type === 'global'
    } else {
      return n.tree_type !== 'global'
    }
  })
})

const groupedNodes = computed(() => {
  const map: Record<string, MemoryNodeDto[]> = {}
  for (const n of filteredNodes.value) {
    const p = n.path |

| '/'
    if (!map[p]) map[p] = []
    map[p].push(n)
  }
  return map
})
</script>

<template>
  <div class="flex flex-col gap-2 font-mono">
    <div v-if="Object.keys(groupedNodes).length === 0" class="text-center text-slate-600 py-8">
      当前记忆树暂无叶子沉淀
    </div>
    <div
      v-for="(items, path) in groupedNodes"
      :key="path"
      class="border border-slate-800/80 rounded bg-slate-950/40 overflow-hidden"
    >
      <div
        @click="toggleCollapse(path)"
        class="bg-slate-800/40 px-2 py-1 flex items-center justify-between cursor-pointer hover:bg-slate-800/70"
      >
        <div class="flex items-center gap-1 text-slate-300 font-semibold">
          <span>{{ collapsedPaths.has(path) ? '▶' : '▼' }}</span>
          <span>📁 {{ path }}</span>
        </div>
        <span class="text-[10px] text-slate-500 bg-slate-800 px-1 rounded">{{ items.length }}</span>
      </div>

      <div v-if="!collapsedPaths.has(path)" class="p-1 flex flex-col gap-1">
        <div
          v-for="leaf in items"
          :key="leaf.id"
          :class="[
            'p-2 rounded border transition-all duration-300',
            store.activeHitIds.has(leaf.id)
              ? 'bg-sky-950/80 border-sky-400 shadow-sm shadow-sky-500/50'
              : 'bg-slate-900/60 border-slate-800 hover:border-slate-700'
          ]"
        >
          <div class="flex justify-between items-center mb-1">
            <span class="font-bold text-sky-300 flex items-center gap-1">
              <span v-if="leaf.is_pinned" class="text-amber-400">📌</span>
              {{ leaf.name }}
            </span>

              <span class="text-[10px] text-slate-500">×{{ leaf.reinforce_count }}</span>

                ×
              </button>
            </div>
          </div>

            {{ leaf.content }}
          </div>
        </div>
      </div>
    </div>
  </div>
</template>

// packages/tlmemory/tests/plugin.spec.ts
import { describe, it, expect, beforeEach, afterEach } from 'vitest'
import { MemoryDB } from '../src/db.js'
import { MemoryRecallEngine } from '../src/recall.js'

describe('dsh-plugin-tlmemory 核心存储与召回测试', () => {
  let db: MemoryDB
  let recall: MemoryRecallEngine

  beforeEach(() => {
    db = new MemoryDB(':memory:')
    recall = new MemoryRecallEngine(db)
  })

  afterEach(() => {
    db.close()
  })

  it('应当正确递归构建物化路径并完成原子规则入库与强化', () => {
    const leaf = db.upsertLeaf(
      'global',
      ['规范', 'TypeScript'],
      '严禁any',
      '工程内必须开启严格类型模式且禁止滥用any',
      ['ts', 'strict', 'any'],
    )

    expect(leaf.path).toBe('/规范/TypeScript/')
    expect(leaf.reinforce_count).toBe(1)

    const reinforced = db.upsertLeaf(
      'global',
      ['规范', 'TypeScript'],
      '严禁any',
      '工程内必须开启严格类型模式且禁止滥用any（强化更新）',
      ['ts'],
    )
    expect(reinforced.reinforce_count).toBe(2)
  })

  it('FTS5 Trigram 应当有效检索中英文混排关键词', () => {
    db.upsertLeaf(
      'repo:test1234',
      ['踩坑', '依赖构建'],
      'pnpm构建拦截',
      'pnpm v11遇到原生C++模块时需使用approve-builds放行',
      ['pnpm', 'better-sqlite3', 'approve-builds'],
    )

    const hitsZh = db.search('原生C++', { treeType: 'repo:test1234' })
    expect(hitsZh.length).toBeGreaterThan(0)
    expect(hitsZh[0].name).toBe('pnpm构建拦截')

    const hitsEn = db.search('approve-builds', { treeType: 'repo:test1234' })
    expect(hitsEn.length).toBeGreaterThan(0)
  })

  it('Prompt 格式化器必须对潜在注入实体进行字符转义', () => {
    db.upsertLeaf(
      'global',
      ['安全规约'],
      '标签隔离',
      '必须对 <system> 与 <script> 进行安全转义编码',
      ['security'],
    )

    const hits = db.search('标签隔离')
    const prompt = recall.formatPromptBlock(hits)

    expect(prompt).not.toContain('<system>')
    expect(prompt).toContain('&lt;system&gt;')
    expect(prompt).toContain('<long_term_memory_context>')
  })
})
```

### 宿主零侵入装配补丁

根据 DSH 架构规范，插件无需修改任何官方核心代码，直接通过在 Profile 的用户补丁层
`$DSH_HOME/profiles/<profile>/cordis.patch.yml`（例如 `~/.dsh/profiles/web/cordis.patch.yml`）
中声明挂载即可。该文件是一个**顶层 YAML 数组**，挂载新插件必须包在 `- insert:` 里
（**只写 `- id: … / name: …` 是「按 id 覆盖已有条目」的语义，条目不存在时会被跳过、
根本挂不上**）：

```yaml
- insert:
    - id: tlmemory-runtime
      name: 'dsh-plugin-tlmemory'
      config:
        serverPort: 4890
        maxRecallCount: 5
        enableAutoReflection: true
        serverEnabled: true
```

> 等价且更省事的方式：`dsh plugin --profile web add dsh-plugin-tlmemory`
> （`tools/dsh-plugin-cmd/` 会按上述形状自动写入，幂等）。完整可用的模板见仓库根目录
> `cordis.patch.example.yml`。

构建与质量核对标准细化如下：

| **校验维度**     | **验收基准**                                   | **违例处置策略**                                             |
| ---------------- | ---------------------------------------------- | ------------------------------------------------------------ |
| **类型声明合并** | `pnpm build` 无任何 TS2339 或导入缺失报错      | 检查 `src/types.ts` 中的 `declare module 'cordis'` 扩充作用域 |
| **原生依赖放行** | `better-sqlite3` 编译不被 pnpm 拦截            | 在 `pnpm-workspace.yaml` 写 `allowBuilds:` + `better-sqlite3: true`（pnpm 11 的键名与形状），或交互式跑 `pnpm approve-builds`；`dsh plugin add` 会自动完成 |
| **装配性能隔离** | `systemPrompt.section` 执行耗时控制在 1ms 以内 | 严禁在装配回调内触发任何异步 I/O，强制读取内存变量           |
| **生命周期注销** | 触发 `dispose` 后端口立即释放，句柄无残留      | 确认 `server.stop()` 与 `db.close()` 绑定在 Disposer 中      |
| **注入防御验证** | 构造包含恶意 XML 标记的文本时输出被安全转义    | 校验 `recall.ts` 中的字符串实体编码转换逻辑                  |



DeepSeek Harness 基于 Cordis 微内核的插件化架构，为长生命周期自主 Agent 提供了极度精炼且可扩展的基座。通过将树状分层记忆拓扑映射为 SQLite 物化路径，并利用 FTS5 Trigram 索引打破中英文混排分词屏障，`dsh-plugin-tlmemory` 建立起一种不依赖外部网络服务的嵌入式高性能持久化范式。系统在会话轮次边界建立起非阻塞的读写分离通道：在会话开始前依托同步内存切片实现零延迟系统提示词注入，在会话结束后依托活跃模型完成去情境化的原子经验反思长叶，同时借助沙箱隔离的 Iframe 与 WebSocket 将知识图谱实时映射至侧边栏控制台。这套方案在严格保证 DSH“无特权内核”与“模型可见即记录”运行时不变式的前提下，为复杂软件研发任务中的长期人机协作构筑了兼具工程严密性与防御纵深的完整工程实现。
